# M10.3: Artifact preload and protected pricing latency (#70)

`src.deployment:app` constructs a protected gateway. The FastAPI lifespan verifies an
**externally pinned** manifest and all artifact hashes before deserializing the TF-IDF,
SVD, scaler and KD-tree joblib files; it loads them once per application worker, not
per request. `/health` reports sanitized artifact provenance/readiness and `/ready`
returns 503 on a missing/untrusted/incompatible bundle or unavailable repository.
An authorized pricing request also returns 503 for unready artifacts without inference
or success audit. Invalid bearer tokens and cross-user mentor IDs cannot start
inference. `src.serve:app` remains local/unauthenticated and must not be deployed.

## Reproduce the local engineering benchmark

Use a reviewed, locally generated proxy-data export (or the deterministic synthetic
bundle from `tests/test_serve.py`). The measured export below was generated from
ignored local `data/processed/harmonized_marketplace_corpus.parquet` and
`data/processed/macro_lookup_table.json` into
`artifacts/exports/issue-70-2026-10-05/`. To regenerate from those local inputs
without overwriting that export:

```powershell
python -m src.train_pipeline --mode evaluate `
  --harmonized-parquet data/processed/harmonized_marketplace_corpus.parquet `
  --macro-lookup data/processed/macro_lookup_table.json `
  --artifact-dir artifacts/exports/issue-70-repro `
  --k-neighbors 5 --no-enforce-quality-gate
```

Point `$bundle` below at `issue-70-repro` to measure that rebuild. This is
**not** a promoted mentor-pricing model. Verify a release pin independently of a
downloaded bundle before running with real artifacts. The self-hash below is only
acceptable for a **self-built local development export**, not deployment trust:

```powershell
$env:OPENBLAS_NUM_THREADS='1'; $env:OMP_NUM_THREADS='1'; $env:MKL_NUM_THREADS='1'
$bundle = 'artifacts/exports/issue-70-2026-10-05'
$pin = (Get-FileHash "$bundle/artifact_manifest.json" -Algorithm SHA256).Hash.ToLowerInvariant()
python -m src.protected_pricing_benchmark `
  --artifact-dir $bundle --manifest-sha256 $pin `
  --tariff-csv tests/fixtures/raw/Mpesa_Tarrifs/tarrifs_full_schedule.csv `
  --samples 100 --warmup 10 --output reports/m10_protected_pricing/latency.json
python -m pytest -q tests/test_protected_pricing_benchmark.py
```

The untracked `reports/` JSON records versions, OS/CPU, source and validation
status, partition sizes, warmup, sample counts, and P50/P95/P99 per operation;
`artifacts/`, `data/`, and `reports/` stay out of Git. The fixture tariff is for
local smoke tests, not an official schedule. If an industry has no trained
partition the corresponding fixture is **reported as skipped**, not silently
routed or counted as a measurement; an empty profile fails.

## Example local result (2026-10-05)

Windows 11 (build 26200), AMD64 (12 logical CPUs), Python 3.13.2, NumPy 2.5.3,
scikit-learn 1.9.0, FastAPI 0.141.1. Proxy marketplace export: 53D IDW k=5,
8 industry partitions, manifest version `v1:d16876fbf055`, source
`upwork_data_scientists, upwork_jobs`, stratified exploratory split,
`exploratory_not_empirically_approved`. BLAS/OMP/MKL threads fixed at 1.
Lifespan startup (manifest verification + deserialization + TestClient startup):
**231.0 ms**, measured once; **not** included in request timings. Each scenario
has 10 warmups **per path**, followed by **100 successful samples per path**.
Percentiles use NumPy linear interpolation over timed successful calls.

| Fixture (mentor KE) | Inference P50 / P95 / P99 ms | Protected TestClient P50 / P95 / P99 ms | Stub verifier P95 ms | Stub audit P95 ms |
| --- | ---: | ---: | ---: | ---: |
| Domestic web/backend (client KE) | 5.517 / 7.371 / 7.870 | 9.481 / 11.086 / 15.100 | 0.001 | 0.047 |
| Cross-border web/backend (client US) | 5.591 / 7.218 / 7.767 | 9.062 / 10.769 / 12.027 | 0.001 | 0.050 |
| Cross-border data/AI (client US) | 5.252 / 8.197 / 8.741 | 8.678 / 10.388 / 12.061 | 0.001 | 0.051 |
| Domestic mobile (client KE) | 5.024 / 6.436 / 7.275 | 8.346 / 10.244 / 11.494 | 0.001 | 0.037 |

Zero failures; stub repository health P95 <= 0.001 ms. Timed inference runs the
**actual preloaded** NLP + metadata + KD-tree + corridor + tariff pipeline.
Protected timing includes FastAPI middleware, validation, stub token verification,
repository health, inference, synchronous stub audit, response encoding and
TestClient overhead. Stub timings are instrumented inside the same requests;
percentiles are not additive. Repeated requests and readiness checks are tested
with joblib deserialization and manifest verification patched to fail if called
after startup. Missing/pinless/incompatible artifacts fail before any joblib
deserialization, with `/ready` 503 and actionable sanitized health state.

**Limitations:** the verifier is not Firebase Admin; the Firestore-shaped
repository is in-memory with no cloud calls. There is no TCP/TLS, real network,
production container, concurrency or simulated 3G in this benchmark. Values are
machine-specific observations, **not a sub-50 ms promise or an HTTP SLA**. The
historical M8.2 250 ms P95 target pertains to its local component profile, not
to this protected network path. The authenticated mobile **3G RTT < 3.0 s**
end-to-end gate belongs to Milestone 14 (#86), after real staging deployment.
