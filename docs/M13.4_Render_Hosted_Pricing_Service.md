# M13.4: Deploy Hosted Pricing Service on Render with PLATFORM_PRICE_KEY Authentication

## 1. Overview & Context

This document specifies the deployment configuration, authentication contract, and backend communication protocol for the hosted Pricing Optimization service on Render (**Issue M13.4**), linking directly to the Career Mentor OS platform adapter.

The platform adapter sends requests to `POST /price` using the `X-Platform-Key` authentication header to retrieve dynamic pricing corridors and comparable peers for mentors.

---

## 2. Service Architecture on Render

| Property | Value |
| --- | --- |
| **Hosting Platform** | Render (Free Tier Web Service) |
| **Blueprint Manifest** | `render.yaml` |
| **ASGI Application** | `src.api.main:app` (FastAPI + Uvicorn) |
| **Python Runtime** | `3.11.10` |
| **Build Command** | `pip install -r requirements.txt && python -m nltk.downloader -q stopwords wordnet && python -m src.data.seed_platform_mentors` |

| **Health Check Path** | `/health` (HTTP 200 with status `HEALTHY`) |
| **Root Landing Path** | `/` (JSON status and endpoint directory) |

## 3. Environment Variables & Secret Configuration

The following environment variables must be configured in Render:

| Variable | Type | Recommended Value / Source | Purpose |
| --- | --- | --- | --- |
| `PLATFORM_PRICE_KEY` | Secret | Generated secure token (e.g. `cmo_pk_7f9b8a3e4d...`) | Authentication key for `POST /price`. Requests must send `X-Platform-Key`. |
| `PRICING_ARTIFACT_DIR` | Config | `artifacts/exports/issue-70-2026-10-05` | Pinned model release directory. |
| `PRICING_ARTIFACT_MANIFEST_SHA256` | Config | `d16876fbf055650d0dd41a69332eef8d66ca38a6d728b1828a30fba133f3e87f` | Cryptographic SHA-256 digest of artifact manifest. |
| `PRICING_TARIFF_CSV` | Config | `config/tariffs/mpesa_p2p_users_2026-08-04.csv` | Versioned Safaricom M-Pesa 15-band P2P tariff schedule. |
| `MLOPS_ADMIN_TOKEN` | Secret | Generated secure token | Token for administrative and metrics endpoints. |
| `PLATFORM_API_EMAIL` | Config | `client@career-mentor-os.co.ke` | Supervisor platform staging API login email for dataset pulling. |
| `PLATFORM_API_PASSWORD` | Secret | `Client2026!` (set in Render dashboard) | Platform staging API login password. |

## 4. Platform Adapter Communication Protocol

### Ingress Endpoint: `POST /price`

**Headers:**
```http
Content-Type: application/json
X-Platform-Key: <PLATFORM_PRICE_KEY>
```

**Request Payload:**
```json
{
  "mentorId": "c61a767b-f0a2-4367-a278-7aa41cda8edc"
}
```
*Note*: `mentorId` maps to the mentor's platform user identifier (`platform_mentor_user_id`). The service also supports fallback matching against `platform_mentor_profile_id` and optional inline query overrides.

### Success Response (In-Scope Technical Mentor):
```json
{
  "min": 721.65,
  "max": 8450.0,
  "comparables": [
    {"peer_index": 18158, "rate": 6655.19, "similarity": 0.463596},
    {"peer_index": 13146, "rate": 721.65, "similarity": 0.463447},
    {"peer_index": 3517, "rate": 8450.0, "similarity": 0.463431},
    {"peer_index": 18459, "rate": 1300.0, "similarity": 0.462624},
    {"peer_index": 21805, "rate": 3055.0, "similarity": 0.462215}
  ],
  "reason": "Weighted from 5 comparable peers to 4099.45 KES including a 57.00 KES M-Pesa surcharge."
}
```

### Out-of-Scope Response (Vocational Mentors, e.g. Culinary, Welding, Electrical):
```json
{
  "min": 0.0,
  "max": 0.0,
  "comparables": [],
  "reason": "Outside scope: Category 'Electrical & Electronics' (VOCATIONAL) is outside the technical model scope"
}
```
*Design Note*: As guided by supervisor feedback, returning an explicit "outside scope" response with valid schema rather than a 500 error or a misleading quote enables the platform adapter to handle vocational mentors gracefully without crashing.

### Error Responses:
- **HTTP 401 Unauthorized**: Missing or incorrect `X-Platform-Key`.
- **HTTP 503 Service Unavailable**: `PLATFORM_PRICE_KEY` environment variable is not configured.
- **HTTP 422 Unprocessable Entity**: Unrecognized `mentorId` with missing required inputs.

## 5. Deployment Step-by-Step Runbook

### Option A: Automatic Blueprint Deployment (Recommended)
1. Commit and push the repository containing `render.yaml`.
2. In the Render Dashboard, click **New +** -> **Blueprint**.
3. Connect the `Price-Optimization-Model` repository.
4. Render automatically parses `render.yaml`, provisions the web service, downloads NLTK resources, and runs `src.data.seed_platform_mentors`.
5. Under **Environment**, copy the auto-generated `PLATFORM_PRICE_KEY` value (or supply your own).
6. Note the public URL: `https://<service-name>.onrender.com`.

### Option B: Manual Web Service Setup
1. In Render Dashboard, click **New +** -> **Web Service**.
2. Build Command: `pip install -r requirements.txt && python -m nltk.downloader -q stopwords wordnet && python -m src.data.seed_platform_mentors`
3. Start Command: `uvicorn src.api.main:app --host 0.0.0.0 --port $PORT`
4. Add environment variables specified in Section 3.
5. Set Health Check path to `/health`.
