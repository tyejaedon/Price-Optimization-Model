# M10.8: Handling Vocational Mentors as Outside Scope on POST /price

## 1. Executive Summary & Context

During dataset review for the Career Mentor OS platform corpus, supervisor directive (3) specified:
> *(3) 170 of our 222 mentors are vocational and the platform will still call `/price` for them — decide what you return, an explicit "outside scope" beats a nonsense quote.*

The platform database contains 222 mentors across Kenya and East Africa. 52 mentors belong to digital/technology specializations (Software Engineering, Data Science, Product, DevOps, Digital Marketing), while 170 mentors belong to vocational and trade disciplines (Culinary & Hospitality, Agriculture & Farming, Automotive & Mechanics, Beauty & Cosmetology, Construction & Building, Healthcare & Medical, etc.).

When the platform's unified dispatch adapter calls `POST /price {"mentorId": "<vocational_id>"}`, falling back to `general_tech` would quote a chef or mechanic as a software developer, while an unhandled `422 Missing Fields` would crash client dashboards. M10.8 introduces an explicit, deterministic "outside scope" contract with zero peer estimation and clear explanation.

---

## 2. Response Contract Design

### 2.1 Default Structured 200 Contract (Client-Safe)
For standard client compatibility with the fixed platform adapter (`min`, `max`, `comparables`, `reason`), the endpoint returns `200 OK` with zero bounds and empty comparables:

```json
{
  "min": 0.0,
  "max": 0.0,
  "comparables": [],
  "reason": "Mentorship category 'Culinary & Hospitality' is outside technical pricing scope. Recommendations are available for software, data, product, and digital specializations only."
}
```

### 2.2 Machine-Readable 422 Error Option (Strict Mode)
Downstream services or audit pipelines can opt into machine-readable `422 Unprocessable Entity` responses by supplying header `X-Platform-Error-On-Out-Of-Scope: true` or configuring `PLATFORM_OUT_OF_SCOPE_AS_ERROR=true`:

```json
{
  "detail": {
    "error": "OUT_OF_SCOPE_CATEGORY",
    "category": "Culinary & Hospitality",
    "message": "Category is outside technical mentorship pricing scope."
  }
}
```

## 3. Architecture & Inference Short-Circuiting

```
                     POST /price {"mentorId": "..."}
                                  │
                       [X-Platform-Key Validated]
                                  │
                    Profile Hydration / Metadata Lookup
                                  │
                     Is Mentor Category Vocational?
                                ╱   ╲
                              YES    NO
                              ╱        ╲
              [Short-Circuit]           [Canonical Pipeline]
     Inference Callable NEVER Invoked     53D Vector Space Projection
     Zero KD-Tree Search Overhead         KD-Tree Spatial Query (k=5)
     Deterministic Outside-Scope DTO      IDW Kernel Rate Smoothing
                                          Corridor & M-Pesa Surcharge
```

### 3.1 Categorization Rules
The detection engine inspects:
1. `request.selected_industry` (inline override).
2. `metadata.platform_category` or `profile.category`.
3. `metadata.platform_mentor_type == "VOCATIONAL"` or `profile.mentor_type == "VOCATIONAL"`.
4. Any category mapped to `None` in `PLATFORM_CATEGORY_PARTITIONS` in `src/data/ingest_platform.py`.

### 3.2 Supported Categories vs. Vocational Out-of-Scope Categories

| Category Type | Examples | Route Handling |
| :--- | :--- | :--- |
| **Supported Technical** | Technology & IT, Software Engineering, Data & AI, Cloud/DevOps, Product Management, Digital Marketing | Full KD-Tree inference, peer comparables, corridor bounds |
| **Out-of-Scope Vocational** | Culinary & Hospitality, Beauty & Cosmetology, Automotive & Mechanics, Agriculture & Farming, Construction & Building, Healthcare & Medical, Transport & Logistics | Short-circuited 200 outside scope (or 422 error mode) |

## 4. Verification & Regression Evidence

1. **Inference Short-Circuit Guarantee:**
   A poison inference callable raising an `AssertionError` verified that `dependencies.inference` is never invoked when a vocational mentor is requested.
2. **Category Accuracy:**
   Validated across 6 distinct vocational categories with explicit category naming in the reason string.
3. **Repository Seeding:**
   `seed_platform_mentor_profiles(..., include_vocational=True)` loads and indexes vocational mentors and user aliases (e.g. `p5` / `u5`), resolving outside-scope responses without manual profile configuration.
4. **Technical Invariants:**
   All 11 platform pricing tests and 12 seeding regression tests passed with zero regressions.
