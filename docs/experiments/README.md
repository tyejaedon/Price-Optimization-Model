# Experimental design and evidence index

This is the entry point for [issue #118](https://github.com/tyejaedon/Price-Optimization-Model/issues/118). Each experiment retains its own issue and report; this index records **what was tested, on which population, and what was not established**. [Assumptions](assumptions.md) distinguish selected engineering defaults from measured evidence; [record template](record_template.md) is for new or revisited experiments.

**Scope:** The current project is a CS implementation. Upwork job rates are posted **budgets**, profile rates are **asking rates**, and the [platform dataset](../Platform_Dataset_Ingestion.md) is **synthetic**. None establishes accuracy for real paid mentor prices. The [#91 scope decision](../Label_Provenance_Audit_91.md) defers verified transactions and the empirical OOT mentor-pricing gate; research here does not block M10–M14, silently change production settings or promote artifacts.

**Evidence classes:** The [assumption register](assumptions.md) identifies **implemented defaults** and **untested rationales** separately from results. The [#73 M-Pesa schedule](../M11.3_Mpesa_Tariff.md) is a **sourced external tariff transcription** with a separate production recheck, not an optimized model parameter. Below, audits, historical exploratory results, documented protocols and dated proxy/engineering measurements are listed separately; none is evidence of paid mentor-price accuracy.

## Update rule

Open an issue and use an issue-numbered topic branch and **draft PR** for each change. Before seeing candidate scores, fill in the [record template](record_template.md) with the hypothesis, independent target, dataset/macro fingerprints, excluded rows, frozen baseline, *one variable* and planned candidates, split, metrics and hardware. Fit transforms on training only; choose by validation; evaluate a genuinely untouched final test once **if one exists**. The #93 final window has already been opened and reported: reusing it is exploratory, not a new blind test. Without a later independent proxy snapshot, report validation/sensitivity and the limitation instead of claiming confirmatory test evidence. Append results **including failures** to the experiment's Markdown record, link it here, and update the [assumptions register](assumptions.md) with the decision. Research-only findings cannot change the deployed 53D schema, trusted tariff data or security policy without a separate scoped review. No raw rows, credentials, report blobs or serialized models belong in Git.
